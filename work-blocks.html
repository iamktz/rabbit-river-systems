Rabbit River Work Blocks

Small, focused systems that get useful work done.

A Rabbit River Work Block combines three things around a bounded piece of business work: Brain, Agent, Human.

← Back to Tools & Resources

Brains know. Agents do. Humans decide.

Brain

The business-specific knowledge, rules, history, examples, preferences, and accumulated learning needed to do the work well.

The Brain belongs to the business.

Agent

The AI or automation capability that performs bounded work such as research, comparison, organization, drafting, monitoring, preparation, or execution within defined limits.

Human

The person who sets objectives, defines boundaries, handles exceptions, makes consequential decisions, and owns the outcome.

How Work Blocks fit together

A Work Block is the smallest useful combination of Brain + Agent + Human around bounded work.

One or more Work Blocks can be connected through a workflow to accomplish a larger business objective.

Use as few Blocks as necessary.

Example: Prospecting

A prospecting system might use Work Blocks to:

  • Find possible prospects.
  • Evaluate fit.
  • Prioritize the best opportunities.
  • Prepare useful context.
  • Leave the actual selling decision and conversation with the human.

Start small. Fix something useful. Learn from what happens. Add another Block only when it earns its place.
