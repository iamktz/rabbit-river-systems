Do I Need an AI Agent?

Start with the job, the decisions it requires, and who should choose what happens next.

Understand the difference

Who chooses what happens next?

These are practical distinctions, not a universal naming standard. More autonomy adds operating responsibilities; it is useful only when it solves a problem simpler approaches cannot.

Automation
Rules determine the next step. A submitted form creates a work item and notifies the right person.
AI assistant
A person directs the work. AI helps research, draft, analyze, or prepare; the person decides what to use.
Bounded agent
AI can choose multiple steps and use approved tools toward a clear objective, within defined limits.
More complex agentic system
Longer-running work, greater autonomy, or multiple cooperating processes. Coordination and oversight become more demanding.

Anthropic’s explanation of workflows and agents describes the underlying distinction between predefined paths and AI-directed action.

The fit test

Use an agent only when choosing the steps adds value.

A stronger candidate

Recurring, multi-step work whose path varies enough that simple automation is insufficient. The objective and boundaries are clear, trustworthy information is accessible, and success and failures can be observed.

Simplify first

A rare task, unclear process, unreliable information, predictable steps, or a job dominated by exceptions. An agent is a poor default when consequences are hard to reverse or nobody can describe success.

Illustrative example

A report with known inputs needs no independent decision-maker.

For a routine report, an existing feature or small automation may be enough. An agent might fit a recurring research task that must choose which approved sources to inspect next, with a clear stop point and human review of the result.

Do not automate a process you cannot describe, observe, and judge.

Authority determines risk

Drafting is different from sending, changing, or spending.

Human judgment owns consequential decisions. An assistant that drafts a reply is different from a system that can send it, edit records, issue refunds, delete data, run code, access financial systems, or make commitments.

Narrow the access
Give it only the information and tools needed for the job. Reading sensitive information is itself a responsibility.
Place approval before consequences
Decide which actions require a person’s approval before they happen. Set spending, time, and action limits.
Make failure visible and recoverable
Keep an action record, test ordinary cases and failures, provide a way to reverse changes where possible, and define when to stop or hand back to a person.

Before you build

“No. You need a better workflow and a small automation.”

That can be the useful answer to the agent question. If the task does justify an agent, permissions, testing, maintenance, and an accountable owner are part of the work.
